# LideKick

**配信の相棒。** LideKick は、視聴者数・フォロワー数・チャット・アラートを、ゲームやブラウザの上に HUD として表示します。シングルモニター環境で特に役立ちます。

> [!IMPORTANT]
> **LideKick は配信画面に映すオーバーレイではありません。** 配信者本人が、alt-tab したりサブモニタに目をやったりせずに「今」を把握するためのツールです。

![Windows のデスクトップに表示された LideKick の HUD。左上にステータスパネル・チャットログ・アラートがまとまっている](assets/hud-on-desktop.webp)

## 機能

- **ステータス HUD** — 現在時刻・配信時間・視聴者数・フォロワー数・サブスク数
- **チャット HUD** — コメントの一覧表示。新着時に効果音を鳴らすこともできます
- **アラート** — フォロー・サブスク・サブギフト・ビッツ・レイド・ウィスパー
- **ダッシュボード** — 別ウィンドウにウィジェットを配置（視聴者数・フォロワー数・配信時間・チャット・アラート・OBS 音声レベルメーター・時計）
- **OBS 連携** — OBS WebSocket 経由で接続

## インストール時の注意

LideKick は**コード署名をしていない**ため、初回起動時に OS の警告が出ます。

- **Windows** — SmartScreen の「WindowsによってPCが保護されました」→ *詳細情報* → *実行*
- **macOS** — Gatekeeper の「開発元を確認できません」
  1. 一度アプリを開こうとして、警告を閉じる
  2. **システム設定 → プライバシーとセキュリティ** を開き、下にスクロールして **このまま開く** をクリック（管理者パスワードを求められることがあります）
  3. 古いバージョンの macOS では、アプリを右クリック → *開く* でも開けます

  **このまま開く** ボタンは、起動に失敗してから 1 時間ほどで消えます。見当たらない場合は、もう一度アプリを起動してから確認してください。

## アップデート

| | |
|---|---|
| **Windows** | アプリ内でダウンロードから適用まで完結 |

macOS でアプリ内更新を成立させるにはコード署名が必要です。署名が無い状態では、ダウンロードを終えた**後の**インストール段階で必ず失敗するため、はじめからダウンロードページへ誘導する方式にしています。
